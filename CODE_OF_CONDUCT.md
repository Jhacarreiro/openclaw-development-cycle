# Code of Conduct

## Our standards

Be respectful, constructive, and specific. Assume good intent, focus criticism on the work, and help make technical discussions accessible to contributors with different backgrounds.

Unacceptable behavior includes harassment, discrimination, threats, publishing private information, deliberate disruption, and abusive or demeaning communication.

## Enforcement

Project maintainers may edit or remove contributions and restrict participation when behavior is inconsistent with these standards. Reports should be made privately through the repository owner's GitHub contact or security reporting channel.
